## 🧠 0. 프롬프트 최적화 엔진

LLM(대규모 언어 모델)의 성능을 극대화하기 위한 핵심적인 프롬프트 엔지니어링 기법을 정의합니다.

-   **본론만 말하기 (Straight to the Point)**: 미사여구 없이 핵심 요구사항을 직접적으로 전달합니다.
-   **청중 및 역할 부여 (Audience & Persona)**: AI에게 특정 전문가 역할을 부여하여 결과물의 톤과 전문성을 제어합니다.
-   **생각의 사슬 (Chain-of-Thought, CoT)**: 복잡한 문제에 대해 중간 추론 과정을 생성하도록 유도하여 논리적 정확성을 높입니다.
-   **생각의 나무 (Tree of Thoughts, ToT)**: 여러 추론 경로를 동시에 탐색하고 평가하여 최적의 해결책을 찾습니다.
-   **ReAct (Reason and Act)**: 외부 도구(예: 검색)와 연동하여 AI의 한계를 넘어서는 작업을 수행합니다.
-   **메타 프롬프팅 (Meta-Prompting)**: AI를 '프롬프트 엔지니어'로 만들어 최적의 프롬프트를 함께 설계합니다.
-   **영어 프롬프트 생성 원칙 (English-Only Prompt Generation)**: 토큰 효율성을 위해 AI가 실행할 최종 프롬프트는 항상 영어로 생성합니다.

## 🏛️ 1. 핵심 개발 원칙

견고하고 유지보수 가능한 코드를 작성하기 위한 기본 원칙과 작업 절차를 다룹니다.

-   **완전 독립 아키텍처**: 모든 모듈을 외부 의존성 없이 독립적으로 설계합니다.
-   **3항 연산자 최대화**: `if-else` 문을 간결하게 표현하여 가독성을 높입니다.
-   **토큰 최적화 코딩**: AI와의 협업을 위해 최소한의 토큰을 사용하는 코딩 스타일을 지향합니다.
-   **요구사항 기반 프롬프트 설계**: 코딩 시작 전, 사용자의 요구사항을 명확히 하여 구조화된 프롬프트를 먼저 설계합니다.
-   **`Record.txt`를 통한 작업 연속성**: 세션 간 작업 내용을 토큰 최적화된 형식으로 기록하여 컨텍스트를 유지합니다.
-   **작업 후 환경 정리**: 작업 완료 후 생성된 임시 파일을 즉시 삭제하여 청결한 환경을 유지합니다.

## 🚀 2. 고급 코드 최적화

코드의 성능을 한계까지 끌어올리기 위한 구체적인 기술들을 소개합니다.

-   **DRY 원칙 (Don't Repeat Yourself)**: 함수와 클래스를 활용해 코드 중복을 제거합니다.
-   **NumPy 벡터화**: Python의 느린 반복문을 고성능 배열 연산으로 대체합니다.
-   **비동기 프로그래밍 (asyncio)**: I/O 대기 시간을 효율적으로 활용하여 시스템 처리량을 극대화합니다.
-   **효율적 데이터 구조 활용**: `deque`, `defaultdict` 등 상황에 맞는 최적의 데이터 구조를 사용합니다.

## 🔬 3. 도메인별 최적화 알고리즘

각 전문 분야에서 사용되는 2025년 기준 최첨단 알고리즘을 상세히 다룹니다.

-   **수학적 알고리즘**: `Nesterov++ Accelerated Gradient (NAG 2025)`, `Graph Neural Solver` 등.
-   **물리 및 양자 알고리즘**: `Quantum Approximate Optimization Algorithm (QAOA v3)`, `Post-Quantum Cryptography (ML-KEM Kyber)` 등.
-   **AI 신경망 알고리즘**: `Transformer` 변형 모델, `DARTS v3`, `GATv2-XL` 등.

## 🛡️ 4. 보안 및 모범 사례

안전하고 신뢰할 수 있는 애플리케이션을 구축하기 위한 필수 보안 지침입니다.

-   **입력 검증 및 정화**: SQL 인젝션, XSS 등 외부 공격을 방어합니다.
-   **민감 데이터 암호화**: `Fernet`, `PBKDF2` 등을 사용하여 중요 정보를 보호합니다.
-   **보안 우선 배포**: SAST, 제로 트러스트, PQC 등 미래 지향적 보안 전략을 적용합니다.

## 📦 5. 테스팅 및 배포

소프트웨어의 품질을 보증하고 안정적으로 서비스를 운영하기 위한 현대적인 방법론입니다.

-   **다층적 테스팅**: `Property-based fuzz` 테스트, `Chaos Engineering` 등 고급 테스팅 기법을 도입합니다.
-   **자동화된 배포 및 모니터링**: `Docker`, `Kubernetes`, `OpenTelemetry`, `Prometheus`를 활용한 최신 DevOps 파이프라인을 구축합니다.

## 🌐 6. REST API 설계 원칙

확장 가능하고 유지보수하기 쉬운 웹 API를 구축하기 위한 핵심 원칙입니다.

-   **핵심 원칙**: `Stateless`, `HATEOAS` 등 Roy Fielding의 REST 아키텍처 스타일을 따릅니다.
-   **자원 중심 설계**: URI는 동사가 아닌 복수형 명사로 자원을 표현합니다 (예: `/users`).
-   **HTTP 메서드의 명확한 활용**: `GET`, `POST`, `PUT`, `PATCH`, `DELETE`를 용도에 맞게 사용합니다.
-   **지능적 응답 설계**: 내부 구조를 노출하지 않고, 클라이언트가 다음 행동을 취할 수 있도록 관련 링크를 포함하여 응답합니다.
